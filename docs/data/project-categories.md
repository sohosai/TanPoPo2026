# 企画の分類データ

企画一覧の絞り込みに使う分類（`ProjectCategory`）は、雙峰祭実行委員会から受け取った2つの CSV から決まり、`apps/api/data/sources/project-categories.json`（キーは企画番号、値は分類）に反映する。

| CSV | 必要な列 | 分類 |
| --- | --- | --- |
| 企画一覧 | `企画番号`・`企画のカテゴリ` | `企画のカテゴリ` の値（食事・スイーツ・ドリンク・物品販売・展示型・参加型・パフォーマンス・音楽） |
| 学術企画 | `企画番号` | 学術（企画一覧での分類より優先） |

企画ごとの分類は、次の順に最初に当てはまるもので決まる。

1. `apps/api/data/sources/committee-projects.json`（手で管理する企画番号の配列）に載っている → 委員会企画
2. 上の CSV に載っている → CSV の分類
3. SOS の企画区分がステージ → パフォーマンス
4. それ以外 → その他

CSV が更新されたら、スクリプトを実行して生成された JSON をコミットする。想定外のカテゴリがある場合はエラーで止まる。

```sh
bun run import:project-categories <企画一覧.csv> <学術企画.csv>
```
