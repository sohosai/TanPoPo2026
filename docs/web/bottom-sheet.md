# BottomSheet 改善仕様と実装順

スマホ表示で地図に重ねる BottomSheet（`apps/web/app/components/layouts/MapPanel/BottomSheet.tsx`）の操作仕様と、段階的に実装する順序をまとめる。

## 1. 前提

### 1.1 対象

- 対象はスマホ表示の BottomSheet とする。PC 表示の SidePanel は対象外とする。
- シートに載る画面は次の2種類に分ける。

| 種類 | 該当ルート | 中身 |
| --- | --- | --- |
| 一覧画面 | `/` | 検索バー、絞り込みチップ、企画一覧 |
| 詳細画面 | `/project/:number`、`/place/:placeId`、`/area/:areaId` | 企画・場所・エリアの詳細。検索バーは出さない |

- 企画・場所・エリアの詳細は、すべて同じ仕様に従う。
- iOS Safari ではキーボードを出しても画面の高さが縮まないため、キーボード表示中は最大段のシートの下部がキーボードに隠れる。これは許容する。

### 1.2 用語

- **段**: シートが止まる高さ。最小段・中段・最大段の3つがある。
- **最大段**: シートの上限の高さ。画面縦幅の95%とし、どの画面でも同じ高さにする。仕様中の「100%」は最大段を指す。
- **中段**: 仕様中の「50%」。画面縦幅の50%の高さ。
- **最小段**: 仕様中の「10%」。検索バー、またはアイコンと企画名など1行分だけが見える高さで、実際に画面の10%であるとは限らない。高さはどの画面でも同じにする。
- **検索確定**: 検索欄でエンターキー（IME の変換確定を除く）を押すか、検索アイコンを押した時点。絞り込み結果は入力中も随時反映する。

## 2. 共通の操作

### 2.1 段と伸縮

- 指を離すと、その位置に「離す瞬間の速度 × 予測係数」を足して止まる位置を予測し、予測位置に最も近い段へ動かす。予測係数は4章で定める。
- この方式により、ゆっくり動かしたときは1段ずつ伸縮し、勢いをつけて動かしたときは途中の段を飛ばして最大段または最小段まで動く。
- 段までの動き方は 2.4 に従う。

### 2.2 スクロールとの受け渡し

- シートが最大段に達していないときに上へスワイプすると、中身はスクロールせずシートが伸びる。スワイプはシートのどこから始めてもよい（取っ手に限らない）。
- 最大段に達しているときに上へスワイプすると、中身がスクロールする。
- 中身が先頭まで表示されているときに下へスワイプすると、シートが縮む。先頭に達していなければ中身がスクロールし、先頭に達したら同じ指の動きのまま続けてシートが縮む。
- 横スクロール（絞り込みチップ、企画詳細の画像カルーセル）は、段に関係なく操作できる。
- スクロールバーは、中身をスクロールできる最大段でだけ出す。中段と最小段ではシートの中のスクロールバーを隠す。
- 上下の移動量が判定距離（4章）に達するまではタップとして扱い、企画行のタップなどを妨げない。

### 2.3 シートの形

- 最大段では、画面の横幅いっぱいに広げ、上の角だけを丸める。
- 中段と最小段では、左右と下に余白を取り、四隅を丸めた浮いたカードにする。最小段では、検索バーや、アイコンと企画名の1行だけが入った小さなカードが、画面の下端から離れて浮く。
- 最小段のカードは、中段より左右の余白を広く取り、横幅を狭くする。中の1行（検索欄、またはアイコン・名前・バツ）を小さな余白で囲む、細いカプセルにする。
- 中段ではカードの上端を画面縦幅の50%の位置に置く。最小段ではカードの高さを最小段の高さ（4章）にする。
- 段の間では、形をシートの位置に合わせて連続的に変える。最大段と中段の間、中段と最小段の間で、それぞれ余白と角丸を線形に補間する。最小段より下へ引っ張ったときは、最小段の形のままカードごと下がる。
- 最小段の下の余白は、画面下端の安全領域（`safe-area-inset-bottom`）より狭くしない。
- 取っ手は、上へ広げられることを示すため、どの段でも見せる。中段と最大段ではカードの上端に重ね、最小段へ寄るにつれて上へ移し、最小段ではカプセルのすぐ上に浮かせる。
- 取っ手は中身の配置に場所を取らない。中身の各ページは、取っ手の下に来るよう自分の上の余白を取る。
- カードの中身はカードの形で切り抜く。中身のスクロールの末尾はカードの下端にそろえる。
- 中段と最小段では、中身の左右に余白を足し、中段ではカードの縁から中身（各ページの左右の余白を含む）の端まで18px空ける。最大段では余白を足さない。
- 中身に足す余白は、最大段と中段の間でだけ位置に合わせて変え、中段と最小段の間では変えない。中身の幅が変わると中身全体のレイアウトをやり直すことになり、動きが重くなるため、地図操作などで最も多い中段と最小段の移動では幅を変えない。
- 最小段でカードが細く低くなる分は、最小段で見える行（検索バー、詳細のヘッダー）だけが、自分の位置や大きさを変えて合わせる。
- カードの角丸は、中の要素の角丸と同心にする。カードの角丸は「中の要素の角丸 + その要素からカードの縁までの余白」とする。中段は検索欄の角丸22pxに余白18pxを足して40px、最小段は検索欄の角丸22pxに余白6pxを足して28pxで、最小段のカードは検索欄を囲むカプセルの形になる。
- 余白と角丸の値は4章で定める。

### 2.4 アニメーション

- 指を離したあとや、画面の操作で段を切り替えるときは、ばねの動きで目標の段へ動かす。
- 指を離したときの速度をばねの初速として引き継ぎ、指の動きとアニメーションの間で速度を途切れさせない。
- ばねは、目標をわずかに行き過ぎてから戻る程度の減衰にする（値は4章）。最大段より上には行き過ぎない。
- 動いている途中のシートを掴むと、いま見えている位置からそのまま指で動かせる。
- シートの形（2.3）、地図コントロール（3.7）、操作バー（3.4）は、シートの位置から毎フレーム計算し、シートと同じ動きで変える。
- 中身の最小段向けの表示（3.2、3.4）も、中段から最小段へ寄る進み具合（中段で0、最小段で1）に合わせて連続的に変える。変えるのは位置・大きさ・透明度だけとし、レイアウトは変えない。段の切り替わりの一点でまとめて変えると、表示がガクンと変わるため。
- 視差効果を減らす設定（`prefers-reduced-motion: reduce`）では、ばねを使わず目標の段へ即座に移す。

### 2.5 最小段の操作範囲とアクセシビリティ

- 最小段で操作を受け付けるのは、浮いたカードの内側だけとする。カードの外の余白（左右と下）は地図の操作を受け付ける。中段も同じ。
- 最小段のカードの内側を触ったときの動きは次のとおり。

| 触れた場所 | 操作 | 動き |
| --- | --- | --- |
| 検索欄 | タップ | フォーカスして最大段に広げる（3.3） |
| 詳細のバツボタン | タップ | 詳細を閉じる（3.5） |
| 取っ手（カプセルの上） | タップ | 中段に広げる |
| 上記以外（名前、余白） | タップ | 中段に広げる |
| カードのどこでも | 上下にドラッグ | 2.1、2.2 に従って伸縮する |

- 「上記以外」の範囲はカード全体（高さは最小段の高さ）なので、取っ手の見た目が小さくても、押せる範囲は縦横とも44px以上になる。中段と最大段では、取っ手を押す代わりにカードのどこからでもドラッグできる。
- 取っ手のボタンは、どの段でも幅44px・高さ24px以上を押せる範囲にする（WCAG 2.5.8 の最小寸法）。最小段ではカプセルの上に浮くため、カプセルの上の地図の上でも押せる。
- 取っ手はボタンにする。ドラッグできない利用者（キーボード、スイッチ操作、スクリーンリーダー）も段を切り替えられるようにするためで、WCAG 2.5.7（ドラッグ操作の代替）に当たる。
  - 押すと、最小段は中段に、中段は最大段に、最大段は中段に切り替わる。
  - 読み上げ名は、最大段では「シートを縮める」、それ以外では「シートを広げる」とする。
- 最小段でキーボード操作によって、カードの外（画面に見えていない中身）へフォーカスが移ったら、シートを中段に広げてフォーカスした要素を見せる。WCAG 2.4.11（フォーカスが隠れない）に当たる。

## 3. 画面ごとの仕様

### 3.1 初期表示

- どの URL で開いても中段から始める。検索条件付きの共有 URL や詳細ページの URL で開いた場合も同じ。

### 3.2 一覧画面

- 検索バーはシート内の上端に置く。最小段でも検索バーは見える。
- 最小段では、検索欄をカードの上下中央に置き、カードの縁から上下左右とも6px空ける。その下の絞り込みチップは隠す。チップは最小段へ寄るにつれて薄くし、中段と最小段の中間で消し切る。
- 検索欄は最小段でも枠線を残し、カプセルの中に同心の検索欄のカプセルが入る形にする。
- 最小段で検索条件が入力済みのときは、検索ワードが入った検索バーだけが見える。

### 3.3 検索バーの操作

| 操作 | キーボード | 段 | 入力値 |
| --- | --- | --- | --- |
| 検索欄をタップ | 出す | 最大段 | そのまま |
| エンターキー（変換確定のエンターを除く） | 閉じる | 変えない（最大段のまま） | そのまま |
| 検索アイコンを押す | 閉じる | 変えない（最大段のまま） | そのまま |
| バツボタンを押す | 閉じない | 変えない | 消す |
| ジャンルボタンを押す | 閉じる | 変えない（最大段のまま） | そのまま |
| シートを手で中段・最小段へ下げる | 閉じる | 下げた段 | そのまま |

### 3.4 詳細画面

- 直前の段にかかわらず中段で開く。地図のピンから開いた場合も、一覧の行から開いた場合も同じ。
- 最小段では、アイコン・名前（企画名、場所名、エリア名）・バツボタンを1行に並べ、カードの上下中央に置く。補足行（分類と団体名、企画数）は見せない。
  - アイコンは40pxに縮め、カードと同心の位置に置く（アイコンからカードの縁まで上下左右とも8px）。
  - 名前は0.8倍（約17px）に縮め、アイコンから14px空けて1行で見せる。1行に収まらない名前は末尾を省略する。
  - バツボタンはカードと同心の位置に置く（ボタンからカードの縁まで上下左右とも10px）。
- 中段から最小段へ寄るにつれて、アイコンと名前は縮みながら、バツボタンとともに最小段の位置へ移る。補足行は薄くなり、中段と最小段の中間で消え切る。1行に収まらない名前は、中間で1行に切り詰める。
- 詳細ページのレイアウトは、ヘッダーの上の余白を除いて変えない。最小段向けの表示は、2.4 のとおり進み具合に合わせた位置・大きさ・透明度の変化で作る。
- ヘッダーは、カードの上端から24px空けて始める（取っ手はこの余白に重なる）。中段のカードの角丸に、アイコンや名前が寄らないようにするため。
- 企画詳細の「地図で見る」ボタンは現行どおり置く。押すと地図をその企画へ寄せ、シートを最小段に下げる。
- 「地図で見る」ボタンを含む下部の操作バーは、中段と最大段ではカードの下端に貼り付く。シートが動いているあいだも、カードの下端から動かさない。最小段へ寄るにつれて薄くし、中段と最小段の中間で消し切る。

### 3.5 詳細画面のバツボタン

- 押す前の段にかかわらず、一覧画面の中段に戻る。ブラウザの戻る操作で詳細から一覧に戻ったときも同じ。
- 一覧画面の検索条件と結果は、詳細を開く前の状態のまま残す。

### 3.6 地図を操作したとき

- シートが出ているときに地図を移動・拡大縮小し、移動量が閾値（4章）を超えたら、シートを最小段に下げる。閾値を超えなければシートは動かさない。
- 数えるのは利用者の指による操作だけとする。詳細を開いたときの自動の移動（`flyTo` など）では下げない。
- ピンのタップは移動に数えない。
- 下げるときのアニメーションは、指を離したときの伸縮と同じ動きで滑らかにする。
- 検索中にキーボードが出ていれば閉じる。

### 3.7 地図コントロール

- 現在地ボタンなどの地図コントロールは、カードの上端に追従して上下する。
- 追従するのは中段までとする。シートが中段より上にあるときは中段の位置に留まり、シートに隠れる。

## 5. Google Maps・Apple Maps との比較

| 項目 | Google Maps | Apple Maps | TanPoPo |
| --- | --- | --- | --- |
| 伸縮とスクロール | 最大まで伸びるまで上スワイプでシートが伸び、中身はスクロールしない | Google と同じ | Google・Apple と同じ |
| 初期状態 | シートなし | 中段。各種アイコンなどを表示 | 中段。企画一覧を表示 |
| 検索バーの位置 | 画面上部。シートに覆われない限り常に表示 | シート内。最小段でも表示。詳細では隠す | Apple と同じ |
| 検索欄タップ時 | キーボードと検索履歴 | キーボードとジャンル候補 | キーボードを出し最大段 |
| 検索結果の段 | 約66%。最大まで伸ばせる | 中段。最大まで伸ばせる | 最大段 |
| 検索結果を最小にしたとき | 検索ワードと1件目の一部 | 入力済みの検索バーのみ | Apple と同じ |
| 詳細を開いたときの段 | 最大。中段・最小にできる | 中段。最大・最小にできる | 中段。最大・最小にできる |
| 詳細の最小段 | ― | 店舗名と操作ボタン | アイコン、企画名、バツボタン |
| 地図を操作したとき | 少しでも動かすとシートを閉じる | 一定の移動量を超えると閉じる | Apple と同じ。閉じる先は最小段 |
| 詳細のバツ | 一覧の最大段 | 一覧の中段 | 一覧の中段。検索条件を残す |
| シートの形 | 全幅で下端に接する | 最大段は全幅。中段と最小段は左右と下に余白を取った浮いたカード | Apple と同じ |

TanPoPo は全体として Apple Maps に合わせる。Apple と違うのは次の3点である。

- 初期状態のシートに企画一覧を出す。
- 検索結果を最大段で見せる。Apple は検索結果に合わせて地図も動くため中段で地図を見せるが、TanPoPo の地図は検索に連動しないため、中段に下げても見せるものがない。
- 地図操作でシートを消さず、最小段に下げる。

| エンターキー | 何も起きない | キーボードを閉じる | 3.3 |
| 検索アイコン | 飾りの画像 | 押せるボタン | 3.3 |
| 検索欄のバツ | 押すと入力欄からフォーカスが外れ、キーボードが閉じる | キーボードを閉じない | 3.3 |
| 詳細のバツ | `navigate('/')` で検索条件が消え、段は変えない | 一覧の中段。検索条件を残す | 3.5 |
| 地図を操作したとき | シートは動かない | 閾値を超えたら最小段 | 3.6 |
| 地図コントロールの位置 | 最小段のすぐ上に固定 | 中段までシートに追従 | 3.7 |
| シートの形 | どの段でも全幅で、上の角だけ丸い | 中段と最小段は浮いたカード | 2.3 |
| 段までの動き方 | 0.45秒の決まった曲線（CSS の transition） | 離したときの速度を引き継ぐばね | 2.4 |
| 取っ手 | ドラッグ専用の飾り | 押して段を切り替えられるボタン | 2.5 |
| 最小段のカードをタップ | 何も起きない | 中段に広げる | 2.5 |

## 7. 実装の順序

一度に入れると確認しにくく壊れやすいため、6段階に分ける。各段階は単独で動作確認でき、その段階だけで出しても今より悪くならない範囲にする。シート全体のジェスチャーは操作感の中心なので、3段の基盤の直後に入れ、以降の段階を最終的な操作感の上で確認する。

| 段階 | 内容 | 対応する仕様 |
| --- | --- | --- |
| 7.1 | 3段の基盤 | 2.1、3.1、4章 |
| 7.2 | シート全体のジェスチャー | 2.2 |
| 7.3 | 画面遷移時の段 | 3.4、3.5 |
| 7.4 | 検索バーの操作 | 3.3 |
| 7.5 | 地図操作でシートを下げる、地図コントロールの追従 | 3.6、3.7 |
| 7.6 | シートの形とアニメーション、最小段の操作範囲 | 2.3、2.4、2.5 |

### 7.1 3段の基盤

- 内容
  - 段を最小・中・最大の3つにし、2.1 の予測位置で止まる段を決める。
  - 最大段を画面縦幅の95%、中段を画面縦幅の50%にする。
  - 初期表示を常に中段にする。`initiallyRaised` と `AppLayout` の `openedWithSearch` は不要になる。
  - `MapPanelApi` の `expand` / `raise` / `collapse` は名前を変えず、それぞれ最大段・中段・最小段へ動かす。呼び出し側は変更しない。
- 対象ファイル: `BottomSheet.tsx`、`AppLayout.tsx`
- 含めないもの: ドラッグ範囲は取っ手のまま。画面遷移時の段も現行のまま。
- 確認
  - 取っ手をゆっくり動かすと3つの段のどれかに止まる。
  - 強く弾くと端の段まで動く。
  - どの URL で開いても中段から始まる。
  - どの段でも一覧を末尾までスクロールできる。

### 7.2 シート全体のジェスチャー

- 内容
  - ドラッグの起点を取っ手からシート全体に広げる。
  - 最大段に達するまでは上スワイプでシートを伸ばし、最大段では中身をスクロールする。中身が先頭のときの下スワイプでシートを縮める。
  - 動き始めの向きで縦横を判定し、横スクロールは段に関係なく通す。
  - 判定距離（4章）未満はタップとして扱い、ドラッグした後のタップは無効にする。
  - 最大段で中身が先頭に達したら、同じ指の動きのままシートの縮みに切り替える。
  - 手で中段・最小段へ下げたらキーボードを閉じる。
- 対象ファイル: `BottomSheet.tsx`
- 含めないもの: 地図側の変更。
- 確認
  - 中段で一覧の上から上スワイプすると、中身がスクロールせずシートが伸びる。
  - 最大段で中身がスクロールし、先頭で下スワイプするとシートが縮む。
  - 絞り込みチップと画像カルーセルを、中段でも横にスクロールできる。
  - 企画行のタップで詳細が開き、ドラッグの後には開かない。
  - iOS Safari と Android Chrome の実機で確認する。

### 7.3 画面遷移時の段

- 内容
  - 企画詳細を開いたら中段にする。場所・エリア詳細は現行どおり中段。
  - 詳細の最小段向けの表示（3.4）を足す。ヘッダーの構造は変えない。
  - 詳細のバツで一覧の中段に戻る。一覧が検索条件を覚えておき、バツで `/?<条件>` へ戻して条件を残す。地図のピンや場所詳細を経由して開いた詳細からも同じ条件へ戻れる。
  - ブラウザの戻る操作も同じ扱いにする。
- 対象ファイル: `routes/project/detail.tsx`、`routes/place/detail.tsx`、`routes/area/detail.tsx`、`routes/project/index.tsx`、`useDetailClose.ts`、`DetailCloseButton.tsx`
- 含めないもの: 検索バーの操作。
- 確認
  - 一覧が最大段・最小段のときに企画を開いても中段で開く。
  - 地図のピンから開いても中段で開く。
  - 詳細を最小段にするとアイコンと企画名が1行で見え、長い企画名は末尾が省略される。
  - 検索した状態で企画を開き、バツで戻ると、一覧の中段に検索条件と結果が残っている。

### 7.4 検索バーの操作

- 内容
  - 3.3 の表のとおりに実装する。
  - エンターキーは `KeyboardEvent.isComposing` を見て、変換確定のエンターではキーボードを閉じない。
  - 検索アイコンをボタンにする。
  - バツボタンは押してもフォーカスを外さない。
- 対象ファイル: `ProjectSearchBar.tsx`
- 含めないもの: シートのジェスチャー。
- 確認
  - iOS Safari と Android Chrome の日本語入力で、変換確定のエンターではキーボードが閉じず、次のエンターで閉じる。シートは最大段のまま。
  - バツで入力が消えてもキーボードが残る。
  - ジャンルボタンでキーボードが閉じる。

### 7.5 地図操作でシートを下げる、地図コントロールの追従

- 内容
  - 利用者の指による地図の移動・拡大縮小を、操作の開始から積算する。閾値（4章）を超えたらシートを最小段に下げ、キーボードを閉じる。
  - `flyTo` などの自動の移動は数えない。MapLibre のイベントに `originalEvent` があるかで見分ける。
  - 地図コントロールを、中段までシートの上端に追従させる。
- 対象ファイル: `BottomSheet.tsx`、`MapControls.tsx`、`AppLayout.tsx`
- 含めないもの: ピンのタップの挙動。
- 確認
  - 地図を少しだけ動かしてもシートは動かず、閾値を超えて動かすと滑らかに最小段へ下がる。
  - 詳細を開いたときの自動の移動ではシートが下がらない。
  - ピンのタップで詳細が中段で開く。
  - 地図コントロールが最小段から中段まではシートの上端に付いて動き、中段より上ではシートに隠れる。

### 7.6 シートの形とアニメーション、最小段の操作範囲

- 内容
  - シートの位置から、カードの左右と下の余白、角丸を毎フレーム計算する。カードの要素で背景と影を描き、`overflow: hidden` と角丸で中身を切り抜く。`clip-path` と違い、枠が変わっても中身を描き直さない。
  - 中身はシートと同じ大きさで固定してカードの中に置き、カードの左の余白の分だけ左へずらして画面上の位置を保つ。カードの大きさが変わっても、中身のレイアウトはやり直さない。
  - 指の動きは、1フレームに1回だけ描画に反映する。
  - 中身に足す余白は、整数pxの値が変わったときだけ書き換える。最大段と中段の間で中身の幅が変わるときのレイアウトを軽くするため、一覧の行には `content-visibility: auto` を付け、画面外の行のレイアウトを省く。
  - 中段から最小段へ寄る進み具合を、CSS 変数 `--sheet-peek` として `data-sheet-morph` を付けた要素へ毎フレーム渡す。シート全体ではなく対象の要素にだけ渡し、スタイルの再計算をその要素の中に留める。各ページはこの変数を使った translate / scale / opacity で最小段の形へ寄る。
  - 段までの動きを CSS の transition から、離したときの速度を初速にしたばねの JS アニメーションに置き換える。地図コントロールと操作バーも同じフレームで動かす。
  - 視差効果を減らす設定では、目標の段へ即座に移す。
  - カードの外では地図を操作できるようにする。
  - 取っ手をボタンにし、押して段を切り替えられるようにする。最小段でカードの余白をタップしたら中段に広げる。最小段でカードの外へフォーカスが移ったら中段に広げる。
- 対象ファイル: `BottomSheet.tsx`、`peekMorph.ts`（新規）、`ProjectSearchBar.tsx`、`routes/project/detail.tsx`、`routes/place/detail.tsx`、`routes/area/detail.tsx`、`ProjectIcon.tsx`、`DetailCloseButton.tsx`、`ProjectListItem.tsx`
- 含めないもの: ドラッグの判定。
- 確認
  - 指を離した瞬間に速度が途切れず、ばねで段に吸着する。強く弾くと、わずかに行き過ぎてから戻る。
  - 中段と最小段で、左右と下に余白のある浮いたカードになり、段の間を動かすと形が連続的に変わる。
  - 中段と最小段の間を動かすと、検索バーや詳細のヘッダーが最小段の形へ連続的に変わり、最小段ではカードの上下中央に収まる。
  - 最小段のカードの左右と下の余白で、地図を動かせる。
  - 最小段で取っ手や名前をタップすると中段に広がる。検索欄をタップすると最大段に広がる。
  - キーボードで取っ手にフォーカスし、Enter で段が切り替わる。
  - 視差効果を減らす設定にすると、アニメーションせずに段が切り替わる。
