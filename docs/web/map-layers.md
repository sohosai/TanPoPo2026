# 地図上の会場情報

地図スタイル（`apps/web/app/components/features/Map/sohosai-map.json`）の上に、会場エリア・建物・屋外ブース（テント）・ステージを重ねて表示する。実装は `apps/web/app/components/features/Map/` の次のファイル。

| ファイル | 役割 |
| --- | --- |
| `campusData.ts` | 企画・場所から、地図の各ソースに流す GeoJSON を組み立てる |
| `campusStyle.ts` | ソース・レイヤの定義（ズームの段階、色、タップ対象のレイヤ、強調表示） |
| `CampusLayers.tsx` | 地図へのレイヤ追加、データの流し込み、タップでのページ遷移、表示中のページに応じた強調 |
| `booths.ts` | 屋外ブースのテントの形（`data/booths.geojson`）と中心 |

データは `shop.list` と `place.list` から作るので、企画や場所が変われば地図も追従する。企画と場所の対応は [企画の実施場所データ](../data/shop-locations.md) を参照。

## ズームごとの表示

| ズーム | 表示 |
| --- | --- |
| 〜16.2 | 会場エリア名（第一エリア・第二・第三エリア・大学会館エリア・体芸エリア）と、エリア内の企画数 |
| 16.2〜 | 企画のある建物のピン（中に企画数）と、その下に建物名。ステージ名 |
| 15.4〜 | ステージのピン |
| 15.6〜18 | 屋外テント列のピン（列で最も多い分類の色）。16.6 からピンの中に企画数 |
| 17.4〜 | 建物名・ステージ名の下に企画数 |
| 18〜 | 屋外ブースのテント（配置図どおりの形・向き、企画の分類の色） |
| 18.2〜 | 建物名の下に、中の企画名（部屋番号順に3件まで、残りは「ほか N件」） |
| 18.3〜 | テントの横に企画名 |

建物の中の企画は、地図上では建物のピンにまとめ、部屋ごとの位置は出さない。ブース番号（`C4` など）は配置のための内部的な番号なので、地図にも一覧にも出さない。

エリアの企画数は、各企画の最初の実施場所がどのエリアの範囲に入るかで数える。エリアの範囲は地図スタイルの塗り分け（`area-1` `area-2-3` `area-kaikan` `area-taigei`）を使う。

ズームで文言が変わるラベルは、段階ごとに別のレイヤにしている。symbol の `text-field` に書いた zoom 式はデータのタイルの整数ズームで評価され、小数の境目で切り替わらないため。

## 操作

- タップ位置の周囲 10px にある対象のうち、タップ位置に最も近いもの（テントは中心、ピンはその位置）を選ぶ。
  - テント: そのブースの企画詳細（`/shop/:number`）を開く。日によって企画が変わるブースは、テント列の企画一覧を開く。
  - 建物のピン・名前・塗り、テント列のピン、ステージのピン: `/place/:placeId`（その場所の企画一覧）を開く。
- `/place/:placeId` は、その場所の企画一覧をシートに出し、シートを半分まで開いて地図をその場所へ寄せる（屋外はテントが見えるズーム 18.5）。建物は部屋番号の先頭の数字で階ごとに分け、同じ企画が複数の部屋にまたがるときは1行にまとめる。
- 場所ページではその場所（テント列ならその列のテントすべて）を、企画詳細ではその企画の実施場所とテントを強調する。企画詳細は、屋外ブースならテントの位置へズーム 18.5 で寄せる（テントを隠さないようピンは立てない）。

## 地図右下のボタン

実装は `apps/web/app/components/features/Map/MapControls.tsx`。

- ホーム: 地図を初期表示（会場全体）に戻す。現在地を追従中なら追従だけ外す（現在地の点は残る）。
- 現在地: MapLibre の `GeolocateControl` で現在地の点と精度の円を出し、追従する。押すたびに 表示・追従 → 停止 と切り替わり、地図を動かして追従が外れた状態から押すと追従に戻る。位置情報が許可されていない・取得できない・会場の外にいるときはメッセージを出す。標準の現在地ボタンは隠している。

## 地図の範囲

動かせる範囲はキャンパス周辺（経度 140.07〜140.135、緯度 36.08〜36.135）、最小ズームは 14。
